**Держит все значки области уведомлений (трея) видимыми на Windows 10/11 — и удерживает их
такими.** Значки, которые Windows прячет в выпадающую область, возвращаются на панель задач,
а наблюдатель на событиях реестра мгновенно возвращает любой значок, который Explorer
снова спрячет после запуска, обновления или перерегистрации приложения.

v8 «Aurora» — **полная переписанная с нуля** версия проекта
[paulmann/windows-show-all-tray-icons](https://github.com/paulmann/windows-show-all-tray-icons)
(v7 «Phoenix», C# WPF / .NET 10): та же исследованная механика реестра, но теперь это
**один нативный Win32-exe на C++ с нулевыми зависимостями при установке** — ни .NET, ни SDK,
ни рантаймов, ни редистрибутивов. Скопируйте exe куда угодно и запустите.

## Зачем существует v8

| v7 «Phoenix” | v8 «Aurora» |
|---|---|
| WPF-интерфейс требует **.NET 10 Desktop Runtime** (или ~150 МБ self-contained) | **Один exe ~800 КБ**, статическая линковка, только системные DLL Windows |
| Три редакции (GUI + PowerShell-модуль + BAT) | **Один exe**: GUI + headless-режим `--watch` + полноценный CLI |
| Тема только системная | **Переключатель Светлая/Тёмная/Системная**, сохранение, автоопределение при первом запуске |
| Только английский | **Английский + русский**, автоопределение, переключение на лету |
| Управление значками через PowerShell | **Тумблеры по каждому значку, поиск, фильтры, исключения, контекстное меню в GUI** |
| — | JSON-снимки с автобэкапом, менеджер снимков, журнал событий, копия диагностики, ручная проверка обновлений |

## Возможности

- **Корректная механика** — пишет `HKCU\Control Panel\NotifyIconSettings\{id}\IsPromoted`:
  то же хранилище, что использует переключатель в параметрах Windows
  (подробнее: [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md)).
- **Защита на событиях** — `RegNotifyChangeKeyValue` по поддереву хранилища, дебаунс 400 мс,
  опциональный резервный опрос, опциональный автоперезапуск Проводника с паузой.
- **Управление по значкам** — показать/скрыть отдельные значки, маски исключений
  (`onedrive.exe`, `*teams*`), поиск, фильтры, извлечённые иконки и дружелюбные имена.
- **i18n: 30 языков** — английский по умолчанию с построчным фолбэком, автоопределение ОС,
  переключение на лету и список с самоназваниями (см. [docs/I18N.md](docs/I18N.md)).
- **Современный Fluent-интерфейс (2026)** — полностью самоотрисованный Win32/GDI+:
  навигационная панель, карточки, анимированные тумблеры, сегментированные переключатели,
  оверлей-скроллбары; **светлая/тёмная/системная тема с быстрым переключателем**,
  8 пресетов акцента или «как в Windows», Per-Monitor-V2 DPI, скругления и тёмный заголовок
  окна Windows 11.
- **Безопасность изменений** — JSON-снимки (схема v8) с автоснимком перед массовыми
  правками, менеджер восстановления/экспорта/удаления, хранение 30 снимков.
- **CLI для админов** — `--promote-all`, `--status --json`, `--watch`, стабильные коды
  выхода (`0/1/2/3`), ротация логов 14 дней.
- **Встроенный установщик (новое в 8.1)** — при первом запуске встроенный мастер спрашивает:
  папка установки (по умолчанию `%LOCALAPPDATA%\Programs\TrayIconGuard`), автозагрузка, ярлыки
  на рабочем столе и в меню «Пуск» — или *просто запустить один раз* портативно. Создаёт запись
  об удалении в «Приложения и возможности»; `--uninstall` убирает всё. По-прежнему ноль
  зависимостей и один exe.
- **Уважение к системе** — только HKCU (админ не нужен никогда), без телеметрии,
  без фоновых проверок обновлений, сворачивание в трей, один экземпляр, автозапуск по желанию.

## Быстрый старт

1. Скачайте `TrayIconGuard-8.0.0-win-x64.zip` из
   [Releases](https://github.com/paulmann/windows-show-all-tray-icons/releases)
   (или соберите сами: [docs/BUILD.md](docs/BUILD.md)).
2. Разблокируйте файл и запустите `TrayIconGuard.exe`. Это вся установка.
3. При первом запуске все значки показываются один раз, защита взводится,
   приходит приветственное уведомление. Тема/акцент/язык — на странице «Оформление».

Опциональная установка для пользователя (ярлык в меню Пуск + запись об удалении):

```powershell
powershell -ExecutionPolicy Bypass -File installer\install.ps1
```

### Headless / развертывание

```powershell
TrayIconGuard.exe --promote-all        # разово показать все, код выхода 0
TrayIconGuard.exe --watch              # headless-защита (заменяет BAT/PS редакции v7)
TrayIconGuard.exe --status --json      # снимок состояния для мониторинга
TrayIconGuard.exe --install-autostart  # ключ автозапуска HKCU Run (--minimized)
```

Полный справочник CLI: [docs/CLI.md](docs/CLI.md). Руководство: [docs/USER-GUIDE.md](docs/USER-GUIDE.md).

## Требования

| Компонент | Требование |
|---|---|
| ОС | Windows 10 1703+ (сборка 15063+), Windows 11, Server 2019/2022/2025 (x64) |
| Рантаймы | **Нет.** Только DLL из состава Windows (user32, gdiplus, comctl32, …) |
| Права | Обычный пользователь. Всё в HKCU; UAC не запрашивается никогда |
| Диск | < 1 МБ |

На сборках без `NotifyIconSettings` (до 1703) приложение корректно сообщает об ограничении
на странице «Панель».
