**На других языках:** [English](README.md) · Русский · [Deutsch](README.de.md) · [中文](README.zh.md) · [Español](README.es.md) · [हिन्दी](README.hi.md)

TrayIconGuard возвращает на панель задач значки, которые Windows прячет в выпадающий список
переполнения, — а **событийный guard** возвращает их снова в тот момент, когда Explorer опять
их скрывает (запуск приложения, обновление, перерегистрация). Программа пишет в то же самое
хранилище реестра, которое использует переключатель «Параметров» Windows, — для текущего
пользователя, без прав администратора, — и поставляет современный Fluent-интерфейс, headless-
режим наблюдателя и полноценный CLI в **одном статически слинкованном exe ~1 МБ**, который
работает на стоковой Windows.

## 🚀 Зачем TrayIconGuard?

Windows запоминает видимость значков трея для каждого значка — и **постоянно забывает**:
каждый раз, когда приложение (пере)регистрирует свой значок уведомления, Explorer пересоздаёт
ключ реестра с `IsPromoted=0`, и значки снова проваливаются в выпадающий список `^`.
Поэтому разовые правки и `.reg`-файлы «распадаются» за считанные часы.

```text
# Что реально происходит на стоковой Windows 10/11
Приложение запустилось / обновилось / перерегистрировало значок
        │
        ▼
Explorer пересоздаёт HKCU\Control Panel\NotifyIconSettings\{id}
с IsPromoted = 0            ← значок только что скрылся
        │
        ▼
Наблюдатель TrayIconGuard (RegNotifyChangeKeyValue, дебаунс ~400 мс)
        │
        ▼
IsPromoted = 1 восстановлен ← значок мгновенно вернулся на панель
```

### Реальная польза

- **⚡ Мгновенно**: событийная модель, а не поллинг — правка применяется меньше чем за полсекунды
- **🎯 Точно**: управление каждым значком, исключения, перетаскивание для порядка, три режима видимости
- **🛡️ Уважительно**: только HKCU, обычный пользователь, никогда не админ, без телеметрии, автозагрузка по желанию
- **📦 Компактно**: один статический exe (~1,05 МБ) — без .NET, рантаймов и редистрибутивов
- **🔁 Самовосстановление**: переживает перезапуски Explorer, обновления приложений и циклы входа в систему

## ✨ Ключевые возможности

### 🛡️ **Корректность и безопасность**

- **Механика уровня «Параметров»** — пишет `IsPromoted` в `HKCU\Control Panel\NotifyIconSettings`,
  то же хранилище, что использует переключатель Windows (см. [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md))
- **JSON-снимки** (схема v8) с автобэкапом перед разрушительными операциями,
  менеджер restore/export/delete, хранение 30 снимков
- **Мягкая деградация** на старых сборках: понятный статус, легаси-фолбэки, без падений
- **Стабильные коды возврата** (`0/1/2/3`) для скриптов и RMM

### 🎯 **Умный движок guard**

- **Событийный наблюдатель**: `RegNotifyChangeKeyValue` по поддереву хранилища + дебаунс,
  опциональный поллинг-фолбэк, обнаружение новых значков, пауза/продолжить
- **Режимы видимости**: *Полный* (показаны все), *Кастомный* (ваш выбор по значкам),
  *Компактный* (скрыть всё, кроме TrayIconGuard) — из меню трея или CLI
- **Управление каждым значком**: показать/скрыть/исключить, маски исключений (`onedrive.exe`, `*teams*`)
- **Перетаскивание** значков для порядка показа, сохраняется на этом ПК
- **Безопасный перезапуск Explorer** с кулдауном и подтверждением

### 🎨 **Современный Fluent UI (2026)**

- Собственная отрисовка Win32/GDI+: nav-rail, карточки, анимированные тумблеры, сегмент-контролы,
  оверлей-скроллбары, Per-Monitor-V2 DPI, скругления и тёмный тайтл-бар Windows 11
- Темы **Светлая / Тёмная / Системная** с быстрым переключателем, сохранением и автоопределением
- **Акцентный цвет**: за Windows или 8 пресетов
- Адаптивная компоновка (nav-rail сворачивается уже 860 px), полная клавиатурная навигация

### 📦 **Встроенный установщик**

- Визард первого запуска: **область** (*Только для меня* / *Для всех пользователей* — один запрос
  UAC), папка установки, автозагрузка, ярлыки на рабочем столе и в меню «Пуск» — или
  *запустить один раз* (portable)
- Запись в «Приложения и возможности»; `--uninstall` удаляет всё (сам запрашивает elevation, если нужно)

### 🔄 **Самообновление через Git**

- Opt-in проверка `update/stable.json` в этом репозитории, скачивание с **SHA-256-пином**,
  самозамена и перезапуск; ручная кнопка + опциональная автопроверка раз в сутки (только balloon)
- Контракт публикации для релиз-инженеров: [Updater_SKILL.MD](Updater_SKILL.MD)

## 🧰 Справка по CLI

| Команда | Действие |
|---|---|
| *(без аргументов)* | запустить tray-резидентный GUI |
| `--minimized` | старт скрытым в области уведомлений |
| `--show` / `--toggle-guard` | IPC работающему экземпляру (показать / пауза-продолжить) |
| `--status [--json]` | напечатать состояние трея и выйти |
| `--promote-all` | показать все скрытые значки и выйти |
| `--restore-defaults` | удалить значения `IsPromoted` (вернуть управление Windows) |
| `--restart-explorer` | безопасный перезапуск оболочки и выход |
| `--backup` / `--restore-latest` | создать / восстановить JSON-снимок |
| `--watch` | headless-цикл guard (событийный наблюдатель, без GUI) |
| `--install-autostart` / `--uninstall-autostart` | управление записью HKCU Run |
| `--install-machine <dir> [--autostart] [--desktop] [--menu]` | тело установки для всех пользователей (требует elevation) |
| `--uninstall` | убрать ярлыки, автозагрузку и установленную копию (сам elevates для machine) |
| `--mode full\|custom\|compact` | режим видимости трея |
| `--check-update` / `--update-now` | проверка обновления по git-фиду / необновляющее обновление |
| `--version` / `--help` | интроспекция |

**Коды возврата:** `0` ok · `1` неверные аргументы · `2` ОС не поддерживается · `3` частичный отказ.

## 🏗️ Как это работает

Основное хранилище (Windows 10 1703+ / 11), на пользователя, без админа:

```text
HKCU\Control Panel\NotifyIconSettings\{<icon-id>}
    IsPromoted            DWORD      1 = на панели, 0 = в выпадающем списке
    ExecutablePath       REG_SZ     процесс-владелец
    IconResource         REG_SZ     путь,-id
    IconSnapshot         REG_BINARY кэш образа
    LastNotificationAddedTime  REG_QWORD
```

Легаси-«подтяжки» (опционально): `EnableAutoTray=0` и удаление политик `HideSCA*` в
`HKCU\…\Policies\Explorer`. Полное исследование, анализ «распада» и список
«не трогать» (`StuckRects3` и др.): [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md).

## 🔄 Самообновление через Git

- Фид: [`update/stable.json`](update/stable.json) в `main` (схема, sha256-пины, примечания)
- Клиент: скачивание WinHTTP → проверка BCrypt SHA-256 → самозамена rename-chain → перезапуск
- Никогда не тихо: диалог подтверждения для ручных обновлений; автопроверка — opt-in,
  ≤ раза в 24 ч, только balloon
- CI пинит фид **из тех байтов, которые релиз реально отдаёт** (`scripts/make_feed.py`),
  поэтому фид и ассеты не могут разойтись — см. [Updater_SKILL.MD](Updater_SKILL.MD)

## 🏢 Развёртывание и автоматизация

- **Task Scheduler / logon-скрипты GPO**: `TrayIconGuard.exe --watch` (headless) или
  `--minimized` (GUI в трее)
- **RMM / мониторинг**: `--status --json`, стабильные коды возврата, ротируемые логи за 14 дней
  в `%LOCALAPPDATA%\TrayIconGuard\logs`
- **Безопасность для парка машин**: per-user не требует админа; machine — через
  `--install-machine` из повышенного контекста
- Готовность к Store: MSIX-манифест + ассеты + скрипт упаковки в [`store/`](store/) — см.
  [docs/STORE.md](docs/STORE.md)

## 🔍 Устранение неполадок

| Симптом | Лечение |
|---|---|
| «Неправильная параллельная конфигурация» при старте | exe распакован в папку с именем `*.exe` или не разблокирован; см. [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) |
| Предупреждение SmartScreen при первом запуске | ожидаемо для неподписанных бинарей: Свойства → Разблокировать; гид по подписи в [docs/SMARTSCREEN.md](docs/SMARTSCREEN.md) |
| Значки снова скрылись после обновления приложения | guard на паузе? меню трея → *Пауза/Продолжить*; вкладка «Активность» покажет события наблюдателя |
| Обновление отклонено: sha256 mismatch | дрейф фида/ассетов — перепубликация по [Updater_SKILL.MD](Updater_SKILL.MD) §3 |
| Ничего не показывается на Win10 < 1703 | хранилище не поддерживается; приложение сообщит и предложит легаси-переключатели |

Ещё: [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) · [wiki FAQ](https://github.com/paulmann/windows-show-all-tray-icons/wiki)

## 🛠️ Сборка из исходников

```bash
# Кросс-сборка на Linux (статический, stripped, exe без зависимостей)
sudo apt install g++-mingw-w64-x86-64 cmake
./scripts/build.sh          # гейты: 0 предупреждений, проверка манифеста, аудит только OS-DLL
./scripts/package.sh        # zip + SHA256SUMS

# Или нативно MSVC на Windows
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

CI гоняет оба варианта на каждый push (ubuntu cross + windows MSVC) и публикует релизы по тегам `v*`.
Подробности: [docs/BUILD.md](docs/BUILD.md).
